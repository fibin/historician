# Ежедневное задание для Claude (работа на подписке, без ключа API)

Эту инструкцию выполняет ежедневное задание Claude. Claude сам делает работу,
которую в режиме API делают `historian/research.py` и `historian/writer.py`.

1. Прочитай `data/history.json`: эти люди и темы уже были. Людей из последних 60 записей не бери.
2. Найди историю, строго следуя промпту `SYSTEM` из `historian/research.py`.
   Используй веб-поиск и открывай источники, подтверди историю минимум двумя независимыми источниками.
3. Напиши посты по промпту `SYSTEM` из `historian/writer.py` (язык — `HISTORIAN_LANGUAGE`, по умолчанию русский).
4. Сохрани результат в `out/<сегодняшняя дата>.json` по схеме `SCHEMA` из `historian/writer.py`
   и добавь поле `dossier` с досье.
5. Проверь черновик: `python -m historian.main --from-draft out/<дата>.json`
   (код обрежет слишком длинные части и откажется от повторяющегося человека).
6. Публикуй только если переменная окружения `HISTORIAN_PUBLISH` равна `true`:
   `python -m historian.main --from-draft out/<дата>.json --publish`,
   затем закоммить `data/history.json` в `main` и запушь.
   Иначе ничего не публикуй и просто покажи черновик.

Генерация и публикация постов в Threads

Как начать
  1. Аккаунты переключаются вкладками вверху. У каждого своя тема, язык, ИИ, токен Threads, время публикации и свой журнал, поэтому материалы не повторяются внутри аккаунта. Новый аккаунт: кнопка «+ Добавить аккаунт».
  2. Опишите тему в поле «О чём аккаунт»: о чём искать материал и какими должны быть посты (тон, формат, что важно). Чем подробнее, тем точнее попадание. ИИ пишет только на эту тему.
  3. Выберите ИИ в «Настройках аккаунта». Если рядом написано «не установлен», выполните шаги под списком, а потом закройте окно Historian и запустите его снова.
  4. Получите токен Threads (для каждого аккаунта Threads свой):
    • Откройте developers.facebook.com/apps → Create App → сценарий Access the Threads API → создайте приложение. Одно приложение подходит для всех ваших аккаунтов.
    • Use cases → Access the Threads API → Customize → Permissions: добавьте threads_basic, threads_content_publish, threads_manage_insights (статистика), threads_read_replies и threads_manage_replies (ответы на комментарии). Если разрешения добавлены после получения токена, получите токен заново: старый их не видит.
    • App roles → Roles → Add People → роль именно Threads Tester (не Instagram Tester) → впишите имя аккаунта Threads. Второй аккаунт добавьте так же.
    • Примите приглашение, войдя в этот аккаунт: threads.net → Настройки → Аккаунт → Разрешения для сайтов → Приглашения → Принять.
    • Проверьте App roles → Roles → Threads Testers: у аккаунта не должно быть пометки Pending. Если она есть, приглашение не принято этим аккаунтом.
    • Важно: в этом же браузере откройте threads.net и войдите в тот аккаунт, для которого нужен токен (из другого аккаунта выйдите). Токен выдаётся тому аккаунту Threads, в который браузер сейчас вошёл. Если этот аккаунт не тестировщик, Meta ответит ошибкой The user has not accepted the invite to test the app.
    • Снова Use cases → Customize → Settings → User Token Generator → Generate access token → скопируйте.
  5. Вставьте токен в блок «Аккаунт Threads» и нажмите «Сохранить токен». ID определится сам, а продлевать токен бот будет сам.
  6. Нажмите «Сгенерировать», прочитайте посты, при необходимости поправьте, затем «Опубликовать».
  7. Видео для Shorts, TikTok и Reels (по желанию): один раз установите FFmpeg. В PowerShell: winget install Gyan.FFmpeg, затем закройте окно Historian и запустите его снова. После этого у поста появится кнопка «Сделать видео». Фоновая музыка: положите mp3 в папку music рядом с Historian.exe.
  8. Каждый день сам (по желанию): поставьте галочку «Публиковать каждый день сам», выберите время, а в блоке «Расписание» внизу нажмите «Включить расписание» (один раз на все аккаунты).

Пост дня

Как заходят посты

ИИ видит, какие посты аккаунта зашли лучше и хуже всего, и подстраивает выбор материала и подачу. Это включается, когда наберётся 4 поста старше двух дней. Цифры обновляются сами раз в 6 часов.

Комментарии

Бот находит новые комментарии под постами последних двух недель, ИИ предлагает ответ, а отправляете вы. Живые ответы автора растят аудиторию, а автоматические выглядят как бот.

Настройки аккаунта

О чём искать материал и какими должны быть посты: тон, формат, что важно. ИИ пишет только на эту тему. Поля сохраняются сами, когда вы переходите к другому.

Для крипипаст, рассказов, сказок выберите «Придумывает свои»: ИИ не ищет в интернете, а сочиняет новую историю на тему аккаунта, без ссылок на источники.

ИИ пишет столько постов, сколько нужно материалу, в этих пределах. Чтобы всегда был один пост, поставьте 1 и 1.

Wikimedia Commons: архивные фото, картины, карты со свободной лицензией, хорошо для истории. Из статьи: главная картинка страницы-источника, хорошо для новостей. Права на неё у издания, поэтому в конце цепочки бот подписывает сайт.

В режиме «Придумывает свои истории» картинку не ищут, а рисуют: ИИ описывает сцену, бесплатный генератор Pollinations.ai рисует несколько вариантов, вы выбираете.

Генерация и публикация постов в Threads

Как начать
  1. Аккаунты переключаются вкладками вверху. У каждого своя тема, язык, ИИ, токен Threads, время публикации и свой журнал, поэтому материалы не повторяются внутри аккаунта. Новый аккаунт: кнопка «+ Добавить аккаунт».
  2. Опишите тему в поле «О чём аккаунт»: о чём искать материал и какими должны быть посты (тон, формат, что важно). Чем подробнее, тем точнее попадание. ИИ пишет только на эту тему.
  3. Выберите ИИ в «Настройках аккаунта». Если рядом написано «не установлен», выполните шаги под списком, а потом закройте и снова откройте Historian.bat.
  4. Получите токен Threads (для каждого аккаунта Threads свой):
    • Откройте developers.facebook.com/apps → Create App → сценарий Access the Threads API → создайте приложение. Одно приложение подходит для всех ваших аккаунтов.
    • Use cases → Access the Threads API → Customize → Permissions: должны быть threads_basic и threads_content_publish.
    • App roles → Roles → Add People → Threads Tester → впишите имя аккаунта Threads. Второй аккаунт добавьте так же.
    • Примите приглашение, войдя в этот аккаунт: threads.net → Настройки → Аккаунт → Разрешения для сайтов → Приглашения → Принять.
    • Снова Use cases → Customize → Settings → User Token Generator → Generate access token напротив нужного аккаунта → скопируйте. Если Threads попросит войти, входите именно в тот аккаунт, для которого нужен токен.
  5. Вставьте токен в блок «Аккаунт Threads» и нажмите «Сохранить токен». ID определится сам, а продлевать токен бот будет сам.
  6. Нажмите «Сгенерировать», прочитайте посты, при необходимости поправьте, затем «Опубликовать».
  7. Каждый день сам (по желанию): поставьте галочку «Публиковать каждый день сам», выберите время, а в блоке «Расписание» внизу нажмите «Включить расписание» (один раз на все аккаунты).

# Historian — бот для генерации и публикации контента в Threads

Бот сам готовит посты на заданную тему и публикует их в Threads. Он ведёт один или несколько аккаунтов,
и у каждого своя тема, язык, ИИ и расписание. Работает на вашем компьютере через подписку Claude, ChatGPT
или аккаунт Google, поэтому платный API не нужен.

## Что умеет

- **Тема аккаунта решает всё.** В поле «О чём аккаунт» описываете, о чём искать материал и какими должны быть
  посты: тон, формат, что важно. Например: «неочевидные факты о космосе простым языком, с цифрами и сравнениями»
  или «короткие практичные советы по продуктивности, один приём на пост, с примером из жизни».
- **Несколько аккаунтов.** У каждого своя тема, язык постов, ИИ, токен Threads, время публикации,
  черновики и журнал опубликованного.
- **Генерация.** ИИ ищет в интернете материал по теме аккаунта, сверяет ключевые факты минимум с двумя
  источниками и пишет цепочку из 1–10 постов для Threads (каждый до 500 символов, в конце ссылка на источник,
  если тема не просит иначе). Длины проверяются кодом, слишком длинный пост аккуратно режется по предложениям.
- **Выбор ИИ.** Claude (подписка Claude), ChatGPT (подписка ChatGPT через Codex CLI), Gemini (аккаунт Google
  через Gemini CLI) или Claude API по ключу.
- **Правка перед публикацией.** Посты можно поправить, удалить или добавить в окне бота.
- **Публикация** вручную кнопкой или каждый день сама в выбранное время, не больше одного поста в день на аккаунт.
- **Без повторов.** Бот помнит, о ком и о чём уже выходили посты в аккаунте, и не возвращается к ним
  два месяца, а темы за всё время передаёт ИИ как «уже было».
- **Токены Threads продлеваются сами** раз в неделю.

Проект начинался как бот исторических историй. Аккаунт, перенесённый из той версии, получает подробную
историческую тему и пишет, как раньше; её можно поменять в окне.

## Быстрый старт (Windows)

1. Установите [Python 3.12+](https://www.python.org/downloads/) (галочка «Add python.exe to PATH»)
   и [Git](https://git-scm.com/download/win).
2. Установите ИИ, через который будут писаться посты. Для Claude в PowerShell выполните
   `irm https://claude.ai/install.ps1 | iex`, затем `claude` и войдите своим аккаунтом Claude.
   Как поставить ChatGPT (Codex) или Gemini, окно бота покажет само.
3. Скачайте бота и поставьте зависимости:
   ```powershell
   git clone https://github.com/fibin/historician
   cd historician
   pip install -r requirements.txt
   ```
4. Дважды щёлкните **`Historian.bat`**. В браузере откроется окно бота, а в нём раздел «Как начать»
   с пошаговой инструкцией: как получить токен Threads, вставить его и сгенерировать первый пост.

Обновление: `git pull` в папке бота, затем снова `Historian.bat`.

## Окно бота

- **Вкладки аккаунтов** и «+ Добавить аккаунт». Всё ниже относится к выбранной вкладке.
- **Пост дня**: «Сгенерировать» (несколько минут), правка постов, «Опубликовать» (внизу появится ссылка на пост).
  Пока в одном аккаунте идёт генерация, можно работать с другим.
- **Настройки аккаунта** сохраняются сами: название, тема, язык, ИИ, галочка «Публиковать каждый день сам» и время.
- **Аккаунт Threads**: вставьте токен и нажмите «Сохранить токен». ID определится по токену.
- **Расписание**: какие аккаунты публикуют сами и во сколько, и кнопка «Включить расписание».
  Она один раз создаёт задачу Windows: бот без окна каждый час проверяет, где пришло время, и публикует.
  Если компьютер был выключен, пост выйдет после включения. Если ИИ или Threads дважды за день
  ответили ошибкой, бот ждёт следующего дня. Логи лежат в `logs\`.

Пока работаете с окном, не закрывайте чёрное окно консоли: это сервер страницы. Страница доступна только с вашего компьютера.

## Токен Threads

На developers.facebook.com создайте приложение со сценарием *Access the Threads API*, разрешения
`threads_basic` и `threads_content_publish`. Добавьте каждый свой аккаунт Threads в роль *Threads Tester*
и сгенерируйте для каждого долгоживущий токен (60 дней). Одного приложения хватает на все аккаунты.
Подробные шаги есть в окне бота, в разделе «Как начать».

## Консоль

```bash
python -m historian.main                       # черновик для первого аккаунта
python -m historian.main --account nauka       # черновик для аккаунта nauka (имя папки в accounts/)
python -m historian.main --engine codex        # другой ИИ на этот запуск: claude-code, codex, gemini, api
python -m historian.main --from-draft accounts/main/out/2026-10-07_100000.json --publish   # опубликовать черновик
python -m historian.main --due                 # то же, что делает расписание: публикует там, где пришло время
python -m historian.main --refresh-threads-token   # продлить токены всех аккаунтов сейчас
python -m pytest -q tests                      # тесты (без сети и ключей)
```

Переменные окружения (в `.env`): `ANTHROPIC_API_KEY` и `HISTORIAN_MODEL` нужны только для ИИ «Claude API»,
`HISTORIAN_PUBLISH=true` публикует без флага `--publish`.

## Где что хранится

- `accounts/<id>/account.json`: настройки и токен аккаунта.
- `accounts/<id>/history.json`: что уже публиковалось в аккаунте.
- `accounts/<id>/out/`: черновики.
- `logs/`: что бот делал по расписанию.

Папка `accounts/` в git не попадает. При первом запуске бот создаёт аккаунт «Основной» из старых настроек
в `.env` и копирует туда журнал `data/history.json` и черновики из `out/`.

## GitHub Actions (через Claude API)

Можно запускать бота не на компьютере, а в GitHub Actions через Claude API (платно, по ключу).
Расписание в `.github/workflows/daily.yml` по умолчанию выключено.

1. *Settings → Secrets and variables → Actions → Secrets*: `ANTHROPIC_API_KEY`, `THREADS_USER_ID`, `THREADS_ACCESS_TOKEN`.
2. Раскомментируйте `schedule` в workflow. Пока переменная `HISTORIAN_PUBLISH` не равна `true`,
   бот только готовит черновик (артефакт `draft` у каждого запуска).
3. Ручной запуск: *Actions → Daily history post → Run workflow* (галочка «Опубликовать»).

Здесь бот ведёт один аккаунт из секретов. После публикации workflow коммитит обновлённый `data/history.json`.

## Устройство

```
historian/
  main.py        запуск, черновик и публикация, повтор при дубле, --due для расписания
  accounts.py    аккаунты: настройки, токены, продление токенов, перенос старых настроек
  research.py    промпт поиска материала по теме аккаунта + веб-поиск
  writer.py      промпт автора, JSON-схема постов
  engines.py     ИИ по подписке: Claude Code, Codex (ChatGPT), Gemini CLI
  web.py         окно бота в браузере (сервер), page.html — сама страница
  llm.py         вызов Claude API: стриминг, продолжение долгого поиска, обработка отказа
  textfit.py     проверка длины и нарезка
  history.py     журнал опубликованного
  publishers/    threads.py (Threads Graph API)
scripts/         задача Windows для расписания
```

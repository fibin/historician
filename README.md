# Historian — бот малоизвестных исторических историй

Бот ведёт один или несколько аккаунтов Threads. У каждого аккаунта своя тема («о чём аккаунт»), язык постов,
ИИ, токен, время публикации и свой журнал. Каждый день для каждого аккаунта бот:
1. **Ищет** в интернете малоизвестную историю о конкретном человеке на тему аккаунта: привычки, причуды, эпизоды из мемуаров,
   дневников и писем современников. Общеизвестные факты отбрасываются, история должна подтверждаться
   минимум двумя источниками (Claude + веб-поиск, `historian/research.py`).
2. **Пишет** посты: цепочку из 1–10 постов для Threads (каждый ≤ 500 символов), со ссылкой на источник
   (`historian/writer.py`). Длины проверяются кодом, лишнее аккуратно режется по предложениям.
3. **Публикует** в Threads, только если публикация явно включена. Иначе сохраняет черновик в `accounts/<id>/out/`.
4. **Запоминает** человека и тему в журнале аккаунта `accounts/<id>/history.json`, чтобы не повторяться
   (люди за последние ~2 месяца исключаются полностью, темы за всё время передаются модели как «уже было»).

Настройки и токены аккаунтов лежат в `accounts/<id>/account.json`. Папка `accounts/` в git не попадает.
При первом запуске после обновления бот сам создаёт аккаунт «Основной» из старых настроек в `.env`
и копирует туда журнал `data/history.json` и черновики из `out/`.

## Локальный запуск

```bash
pip install -r requirements.txt
python -m historian.main                       # черновик для первого аккаунта его ИИ
python -m historian.main --account nauka       # черновик для аккаунта nauka (имя папки в accounts/)
python -m historian.main --engine api          # другой ИИ на этот запуск (api: нужен ANTHROPIC_API_KEY)
python -m historian.main --from-draft accounts/main/out/2026-10-07_100000.json --publish   # опубликовать черновик
python -m historian.main --due                 # то, что делает планировщик: публикует там, где пришло время
python -m pytest -q tests                      # тесты (без сети и ключей)
```

Переменные окружения: `HISTORIAN_MODEL` (модель для `--engine api`, по умолчанию `claude-opus-5-5`),
`HISTORIAN_PUBLISH=true` (публиковать без флага `--publish`). `HISTORIAN_LANGUAGE` и `THREADS_*` нужны
только для создания первого аккаунта.

## Ключи

**Claude API** — нужен только для `--engine api`: `ANTHROPIC_API_KEY` из console.anthropic.com.

**Threads** — в developers.facebook.com создать приложение с продуктом *Threads API*, разрешения
`threads_basic` и `threads_content_publish`, добавить каждый свой аккаунт Threads тестировщиком и получить
для каждого **долгоживущий** токен (60 дней). Одного приложения хватает на все аккаунты. Токен вставляется
в окне бота; бот сам продлевает его раз в неделю, когда запускается (окно или расписание).
Продлить все токены сразу: `python -m historian.main --refresh-threads-token`.

## Окно бота (без консоли)

Дважды щёлкните **`Historian.bat`** в папке бота. Откроется страница в браузере:
- **Как начать**: пошаговая инструкция прямо в окне.
- **Вкладки аккаунтов** и «+ Добавить аккаунт». Всё ниже относится к выбранной вкладке.
- **История дня**: «Сгенерировать» (ИИ ищет историю и пишет посты, несколько минут), правка, удаление
  и добавление постов, «Опубликовать» (внизу появляется ссылка на пост). Пока в одном аккаунте идёт
  генерация, можно работать с другим.
- **Настройки аккаунта** сохраняются сами: название, «О чём аккаунт» (тема, по которой ИИ ищет истории),
  язык постов, ИИ (Claude по подписке, ChatGPT через Codex CLI, Gemini CLI или Claude API по ключу;
  если программа не установлена, окно покажет, как её поставить), галочка «Публиковать каждый день сам» и время.
- **Аккаунт Threads**: вставьте токен и нажмите «Сохранить токен». ID определится по токену.
- **Расписание**: какие аккаунты публикуют сами и во сколько, и кнопка «Включить расписание» (задача Windows).

Пока работаете с ботом, не закрывайте чёрное окно консоли: это сервер страницы. Страница доступна только с вашего компьютера.

## Запуск на своём компьютере (Windows, на подписке Claude)

В этом режиме историю ищет и пишет **Claude Code**, вошедший в вашу подписку Claude,
поэтому ключ API не нужен. Тратятся лимиты подписки.

1. Установите [Python 3.12+](https://www.python.org/downloads/) (галочка «Add python.exe to PATH»)
   и [Git](https://git-scm.com/download/win).
2. Установите Claude Code и войдите своей подпиской. В PowerShell выполните
   `irm https://claude.ai/install.ps1 | iex`, затем `claude` и выберите вход через аккаунт Claude.
3. Скачайте бота и поставьте зависимости:
   ```powershell
   git clone https://github.com/fibin/historician
   cd historian
   pip install -r requirements.txt
   copy .env.example .env
   ```
4. Запустите `Historian.bat`, вставьте токен Threads и нажмите «Сгенерировать». Займёт несколько минут,
   черновик появится в окне и в `accounts\<id>\out\`.
5. Ежедневная публикация: в окне бота у нужных аккаунтов поставьте «Публиковать каждый день сам» и время,
   затем в блоке «Расписание» нажмите «Включить расписание» (или выполните
   `powershell -ExecutionPolicy Bypass -File scripts\install_task.ps1`). Задача Windows запускает бота
   без окна каждый час, а он публикует в тех аккаунтах, где время уже пришло, не больше одного поста в день
   на аккаунт. Если компьютер был выключен, пост выйдет после включения. Если ИИ или Threads дважды за день
   ответили ошибкой, бот ждёт следующего дня. Логи лежат в `logs\`.

## Ежедневный запуск через GitHub Actions (режим API)

Расписание в `.github/workflows/daily.yml` по умолчанию выключено; чтобы работать через API, раскомментируйте `schedule`.

1. Положите код в репозиторий на GitHub.
2. *Settings → Secrets and variables → Actions → Secrets*: добавьте все ключи выше.
3. Пока переменная `HISTORIAN_PUBLISH` не задана, бот только готовит черновик (он лежит в артефакте `draft`
   у каждого запуска). Посмотрите несколько черновиков, и когда качество устроит, задайте
   *Variables → `HISTORIAN_PUBLISH` = `true`*.
4. Ручной запуск: *Actions → Daily history post → Run workflow* (галочка «Опубликовать»).

Здесь бот ведёт один аккаунт из секретов `THREADS_*`. После публикации workflow коммитит обновлённый `data/history.json`.

## Устройство

```
historian/
  main.py        запуск, черновик/публикация, повтор при дубле человека, --due для планировщика
  accounts.py    аккаунты: настройки, токены, продление токенов, перенос старых настроек
  research.py    промпт исследователя + веб-поиск
  writer.py      промпт автора, JSON-схема постов
  engines.py     движки на подписке: Claude Code, Codex (ChatGPT), Gemini CLI
  web.py         окно бота в браузере (сервер), page.html — сама страница
  llm.py         вызов Claude: стриминг, продолжение долгого поиска, обработка отказа
  textfit.py     проверка длины и нарезка
  history.py     журнал опубликованного
  publishers/    threads.py (Threads Graph API)
```
